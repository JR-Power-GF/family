## 配置步骤

### 1. 创建数据库集合

1. 打开微信开发者工具
2. 点击工具栏「云开发」按钮
3. 进入「数据库」
4. 点击「添加集合」
5. 输入集合名称：`stories`
6. 点击确定

### 2. 设置数据库权限

1. 在数据库中点击集合 `stories`
2. 点击「权限设置」标签
3. 选择「所有用户可读，仅创建者可写」
4. 点击保存

### 3. 上传云函数

1. 在开发者工具左侧文件目录中找到 `cloudfunctions/getUserInfo`
2. 右键点击 `getUserInfo` 文件夹
3. 选择「上传并部署：云端安装依赖」
4. 等待上传完成

### 4. 测试流程

1. **打开小程序** → 应显示空白状态（还没有故事）
2. **点击 "+" 按钮** → 进入发布页面
3. **选择照片** → 从相册选择或拍照
4. **输入故事文字** → 写下你的故事
5. **点击「发布」** → 等待上传完成
6. **返回首页** → 故事应显示在时间线中

## 数据库结构

### stories 集合

| 字段 | 类型 | 说明 |
|------|------|------|
| `_id` | string | 自动生成的文档ID |
| `photoUrl` | string | 云存储文件ID (cloud://...) |
| `caption` | string | 故事文字内容 |
| `authorId` | string | 作者的 openid |

| `authorAvatar` | string | 作者头像URL |

## 常见问题

### Q: 发布失败怎么办？
A: 检查云开发是否已开通，数据库集合是否已创建，权限是否正确设置。

### Q: 图片无法显示？
A: 云存储中的图片需要通过 `wx.cloud.getTempFileURL` 转换为临时URL才能显示。代码已处理此逻辑。

### Q: 如何查看云开发控制台？
A: 微信开发者工具 → 工具栏「云开发」按钮
