# Design: Offline Queue Support

Generated by brainstorming on 2026-03-29

## Problem Statement

Users in spotty network conditions (subway, elevator, rural areas) cannot post stories. When they attempt to post offline, the upload fails and they lose their work. Older family members may not understand why the app "doesn't work" and give up.

## Solution Overview

Implement a local queue system that:
1. Saves stories locally when offline
2. Shows pending stories in timeline with sync status badge
3. Auto-syncs when network returns
4. Provides manual retry for failed items

## Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Posting while offline | Queue locally, auto-sync later | Matches user expectation from WhatsApp/WeChat; reduces friction for older users |
| Offline viewing | Not in scope (focus on queue) | Keep scope focused; existing cache handles recently viewed |
| Pending in timeline | Show with "⏳ Syncing..." badge | Immediate feedback; user knows story is there |
| Sync failures | Notify after 3 attempts | Balance persistence with user control |
| Pending management | Tap offline banner for list | Contextual, non-invasive, hidden when not needed |

## Sync Logic

### Trigger Points

| Event | Action |
|-------|--------|

| Network reconnect | Immediately sync queue |

### Status Mapping

| Queue `status` | Timeline `syncStatus` | Badge |
|----------------|----------------------|-------|
| `'pending'` | `'pending'` | ⏳ 等待同步 |
| `'syncing'` | `'syncing'` | ⟳ 同步中... |
| `'failed'` | `'failed'` | ⚠️ 点击重试 |

### Sync Manager (`utils/syncManager.js`)

```javascript
import { getCompressedImage } from './image.js'

// Reuse existing compression + upload logic from add-story
async function uploadPhotos(photoFiles) {
  const uploadedUrls = []

  for (const photo of photoFiles) {
    // Compress (same as add-story flow)
    const compressed = await getCompressedImage(photo.path, {
      maxSizeKB: 500,
      quality: 80
    })

    // Upload to cloud
    const cloudPath = `stories/${Date.now()}-${Math.random().toString(36).slice(2)}.jpg`
    const { fileID } = await wx.cloud.uploadFile({
      cloudPath,
      filePath: compressed.path
    })

    uploadedUrls.push(fileID)
  }

  return uploadedUrls
}

export const syncManager = {
  isSyncing: false,

  async syncAll() {
    if (this.isSyncing) return
    this.isSyncing = true

    const queue = getOfflineQueue()

    for (const item of queue) {
      if (item.status === 'failed' && item.attempts >= 3) continue
      await this.syncItem(item)
    }

    this.isSyncing = false
  },

  async syncItem(item) {
    updateQueueItem(item.id, { status: 'syncing' })
    updateTimelineStory(item.id, { syncStatus: 'syncing' })

    try {
      const uploadedUrls = await uploadPhotos(item.photoFiles)

      await storiesApi.createStoryFromQueue({
        photoUrls: uploadedUrls,
        caption: item.caption,
        authorId: item.authorId,
        authorName: item.authorName,
        authorAvatar: item.authorAvatar,
        queuedAt: item.queuedAt
      })

      removeFromQueue(item.id)
      replaceLocalStoryWithReal(item.id, realStory)
      showSyncSuccess(item)

    } catch (error) {
      const newAttempts = item.attempts + 1
      const status = newAttempts >= 3 ? 'failed' : 'pending'

      updateQueueItem(item.id, {
        attempts: newAttempts,
        status,
        lastAttemptAt: Date.now()
      })
      updateTimelineStory(item.id, { syncStatus: status })

      if (status === 'failed') {
        showSyncFailedNotification(item)
      }
    }
  }
}
```

### `utils/offline.js` (Enhanced)

```javascript
export function getPendingStories() {
  const queue = getOfflineQueue()
  return queue.map(item => ({
    _id: item.id,
    photoUrl: item.photoFiles[0]?.path,
    photoUrls: item.photoFiles.map(f => f.path),
    caption: item.caption,
    authorName: item.authorName,
    authorAvatar: item.authorAvatar,
    createdAt: item.queuedAt,
    isPending: true,
    syncStatus: item.status
  }))
}

export function updateQueueItem(id, updates) {
  const queue = getOfflineQueue()
  const index = queue.findIndex(item => item.id === id)
  if (index !== -1) {
    queue[index] = { ...queue[index], ...updates }
    uni.setStorageSync(OFFLINE_QUEUE_KEY, JSON.stringify(queue))
  }
}

export function removeFromQueue(id) {
  const queue = getOfflineQueue()
  const filtered = queue.filter(item => item.id !== id)
  uni.setStorageSync(OFFLINE_QUEUE_KEY, JSON.stringify(filtered))
}
```

## Error Handling

| Scenario | Handling |
|----------|----------|
| Photo upload fails | Increment attempts, keep in queue, show failed badge |
| Database write fails | Increment attempts, don't remove from queue |
| Partial upload (3/5 photos) | Rollback — delete uploaded photos, retry entire story |
| App killed during sync | On next launch, reset 'syncing' items to 'pending' |
| Photo file deleted | Remove from queue, notify user |
| Duplicate post | Server-side dedup by queuedAt timestamp |

### Stale State Recovery

```javascript
// On app launch, clean up orphaned 'syncing' items
export function recoverStaleItems() {
  const queue = getOfflineQueue()
  queue.forEach(item => {
    if (item.status === 'syncing') {
      // App was killed during sync, reset to pending
      updateQueueItem(item.id, { status: 'pending' })
    }
  })
}
```

## Helper Functions

```javascript
// utils/uiHelpers.js (or inline in components)

export function showSyncSuccess(item) {
  // Update story card badge to "✓ Posted!" for 1.5s, then remove badge
  updateTimelineStory(item.id, { syncStatus: 'success' })
  setTimeout(() => {
    updateTimelineStory(item.id, { isPending: false, syncStatus: null })
  }, 1500)

  uni.showToast({
    title: '故事已同步',
    icon: 'success'
  })
}

export function showSyncFailedNotification(item) {
  // Show system notification / in-app toast
  uni.showToast({
    title: `"${item.caption.slice(0, 20)}..." 同步失败`,
    icon: 'none',
    duration: 3000
  })

  // Update badge to failed state
  updateTimelineStory(item.id, { syncStatus: 'failed' })
}
```
